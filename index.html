App grátis para Mac, Windows e Linux

Agentes, terminal, banco e notas. Numa janela só.

O Cadente é um app que junta as ferramentas do seu dia: o Claude Code e o Codex trabalhando lado a lado, o terminal, a API, o banco, as notas e a agenda. Cada parte da tela é um plugin, e você liga só o que usa. Não quer IA? Desligue tudo e fique com o resto. É grátis e feito em Rust.

    Feito em Rust

    Leve de verdade.
    Sua bateria
    agradece.

    O Cadente não é um site disfarçado de app. Não tem Electron, nem navegador escondido, nem Node rodando por trás. É Rust do núcleo à interface, e dá para sentir a diferença no ventilador do notebook.

    cadente
├─ core       rust
├─ interface  rust · slint, desenhada pela GPU
├─ terminal   rust · pty nativo
├─ agentes    rust · claude, codex, agy e qualquer cli
└─ plugins    rust · webassembly para os da comunidade
    • Menos memóriaNada de um Chromium inteiro por janela. O histórico mora no disco e só sobe quando você abre, então o app não engorda com o tempo.
    • Menos bateriaA tela só redesenha o que mudou. Se nada acontece, o Cadente fica quieto e deixa o processador descansar.
    • Sem nada escondidoFechou a folha, fechou o que estava nela. Terminal, agente ou plugin não fica rodando escondido depois.

      Arquitetura de plugins

      Tudo é plugin.
      E quem decide é você.

      Aqui nada é sagrado. O Chat, o Terminal, a barra lateral, o provider de IA e até o tema são plugins, igualzinho aos da comunidade. Não gostou de algum? Desligue, troque por outro ou tire de vez. Vale para a IA também: desligue e o Cadente vira um hub de produtividade, com terminal, banco, notas, agenda e foco.

            Creator mode em breve

            Teve uma ideia?
            Vire plugin e ganhe com ela.

            Conte para o agente o que você quer e ele escreve o plugin para você. Abaixo, três pedidos de verdade: um Cadu de estimação que fica solto na tela, um painel com as vendas do dia e um tradutor que usa IA. Cada um ganha de um jeito. E com o Cadu dá para brincar: arraste, dê comida e um banho nele.

            1. Conte a ideiaUm Chat abre com o pedido. Nada é enviado até você apertar ↵.
            2. O agente escreveManifesto, código e testes, numa folha ao lado de onde você está.
            3. Teste na horacadente plugin dev põe o plugin para rodar ali mesmo, ao lado da conversa. O Cadu vive solto por cima do app: arraste ele, aperte f para dar comida e b para o banho.
            4. Publique/publish e pronto, ele está na loja, com o preço que você escolheu.
