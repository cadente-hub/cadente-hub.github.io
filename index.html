04Plugins

A tiny core.
Everything else snaps in.

Cadente is built as a microkernel. Models, chat, terminals, tools and even the navigation are plugins wired through versioned contracts — so any of them can be replaced, including by one you write.

Collision · cadente.compaction@1 already has a provider

A small Rust microkernel owns only what must never be swapped: trust, permissions, integrity, isolation, persistence, resolution and recovery.

  • One path for every plugin. Built-in packages and yours go through the same graph, lifecycle and contracts.
  • Checked before it runs. Artifacts are pinned by hash, locked, and granted only the permissions they declare. External code never runs inside the privileged process.
  • Code goes, data stays. Turning a plugin off never deletes its configuration or data.

06Built with Rust

Light while it works.
Gone when it rests.

A small Rust core does the work, so chats, agents, terminals and automations keep running from the tray. Close the window and the interface is released from memory entirely — nothing lingers in the background pretending to be closed.

  • Bounded buffers for terminals and logs, so memory does not creep
  • Workspaces, history and keys stay on your machine
  • Signed updates, and a launcher that can roll back to an earlier version
  • Builds for macOS (Apple Silicon and Intel), Windows and Linux
