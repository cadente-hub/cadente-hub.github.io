    Da ideia à loja, sem sair do Cadente.

    Três pedidos de exemplo, cada um ganhando de um jeito: um Cadu de estimação solto na tela, um painel com as vendas do dia e uma status page que avisa quando o GitHub, a Cloudflare ou a AWS caem. O Cadu dá para arrastar, alimentar e dar banho.

    1. Conte a ideiaUm Chat abre com o pedido. Nada é enviado até você apertar ↵.
    2. O agente escreveManifesto, código e testes, numa folha ao lado de onde você está.
    3. Teste na horacadente plugin dev põe o plugin para rodar ali mesmo, ao lado da conversa. O Cadu vive solto por cima do app: arraste ele, aperte f para dar comida e b para o banho.
    4. Publique/publish e pronto, ele está na loja, com o preço que você escolheu.

    Feito em Rust

    Rust do núcleo
    à tela.
    O ventilador nem liga.

    Sem navegador escondido e sem Node rodando por trás. O Cadente é nativo, desenhado pela GPU, e só gasta energia quando alguma coisa muda na tela.

    cadente
├─ core       rust
├─ interface  rust · slint, desenhada pela GPU
├─ terminal   rust · pty nativo
├─ agentes    rust · claude, codex, agy e qualquer cli
└─ plugins    rust · webassembly para os da comunidade
    • Menos memóriaO histórico fica no disco e só sobe quando você abre. O app não engorda com o tempo.
    • Menos bateriaParou de digitar? O Cadente para junto e deixa o processador descansar.
    • Nada escondidoFechou a folha, acabou. Terminal, agente ou plugin não fica rodando por trás.
