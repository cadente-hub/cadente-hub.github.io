Cadente adalah aplikasi desktop native yang terintegrasi dengan API Claude AI milik Anthropic. Aplikasi menyediakan perangkat untuk pemrograman berbantuan AI, pengelolaan Git, emulasi terminal, pengujian API, serta fitur produktivitas. Fitur tertentu memerlukan kunci API Anthropic yang sah yang Anda sediakan sendiri. Aplikasi semata-mata merupakan alat — seluruh keluaran dihasilkan oleh sistem AI pihak ketiga dan wajib Anda tinjau serta validasi sebelum digunakan dalam bentuk apa pun. Kami tidak memberikan pernyataan apa pun mengenai kesesuaian Aplikasi atau keluarannya untuk tujuan apa pun.
