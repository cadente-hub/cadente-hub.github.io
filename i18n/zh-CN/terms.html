隐私政策

我们非常重视您的隐私。本部分说明 Cadente 收集哪些数据以及如何使用这些数据。

我们收集的数据

Cadente 是一款本地优先的应用程序。我们可能收集以下数据：

  • 账户数据：当您创建账户时，我们会收集您的电子邮件地址，以便通过 Supabase 对您进行身份验证。
  • 使用数据：我们不收集遥测数据、使用情况分析数据或行为数据。零追踪，无一例外。
  • API 密钥：您的 Anthropic API 密钥仅存储于您的本地设备，绝不会传输至我们的服务器。

我们如何使用您的数据

我们收集的数据仅用于：

  • 对您的账户进行身份验证
  • 向您发送与账户相关的事务性电子邮件

我们不会出于营销目的向第三方出售、出租或共享您的个人数据。

第三方服务

我们使用以下服务运营本应用：

  • Supabase：身份验证与账户管理（隐私政策）
  • Anthropic：AI API，由您的设备直接调用（隐私政策）

数据保留与删除

您可随时通过在我们的 GitHub 代码仓库中提交 Issue，申请删除您的账户及相关数据。我们将在 30 日内处理删除请求。
